# 🎼 Openheinerss (OpenHarness)

> **"Regendo a orquestra universal de agentes e harnesses de IA."**

<p align="center">
  <img src="./logo.jpg" alt="Openheinerss Maestro" width="400" />
</p>

O **Openheinerss** é um maestro universal de orquestração de **AI Coding Agents**.

Em vez de prender sua aplicação ao Claude Code, OpenCode, Codex ou qualquer CLI proprietário, o Openheinerss fornece:
1. **Um binário Go de alta performance** que gerencia os processos filhos, permissões e streaming.
2. **Um protocolo unificado de mensagens** (JSON-RPC) para qualquer linguagem consumir facilmente.
3. **Múltiplos Harnesses plugáveis** com alternância simples de motores, modelos e provedores.
